## Lecciones registradas

1. **Latin1String cast solo aplica via Eloquent, no Query Builder raw**.
   Si necesitas leer `modulo.nombre`, `tecnico.nombre_completo` u otra
   columna con charset latin1 cp1252, usa el modelo Eloquent
   correspondiente (Modulo, Tecnico). El `DB::table()` directo
   devuelve mojibake.

2. **Filter SelectFilter::make en Filament 3 puede fallar silenciosamente**
   con la inferencia de columna. Patrón defensivo: añadir `->query()`
   explícito siempre que se quiera asegurar el WHERE. Aplicado a 5
   Resources.

3. **N+1 en RelationManager**: cualquier columna con `state(fn
   (Record) => DB::table()->...)` ejecuta query por fila. Solución:
   cache estático `getMap(): array` con la query precargada en una
   sola pasada al primer acceso.

4. **Smoke real prod sigue cazando lo que tests Pest no**: los 2 bugs
   UX detectados (municipio numérico + filter status silencioso) NO
   estaban cubiertos por los 27 tests Pest del 12f. Patrón consolidado.
