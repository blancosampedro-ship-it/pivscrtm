## Lecciones registradas

1. **Option B con AsignacionCierreService funciona end-to-end**: el cierre de
   un preventivo desde PWA crea correctamente la cadena legacy
   `averia stub → asignacion stub → revision` reusando el service Bloque 11b
   sin duplicar lógica. La trazabilidad en el módulo nuevo
   (`lv_revision_pendiente.asignacion_id`) permite navegación bidireccional
   prod ↔ legacy.

2. **CASCADE chain `lv_ruta_dia → lv_ruta_dia_item → lv_ruta_dia_item_imagen`**
   funcionando: un solo `DELETE FROM lv_ruta_dia` eliminó 29+1 filas
   transitivamente. Cleanup transaccional limpio.

3. **Web Speech API es-ES requiere HTTPS** real. ngrok free expone HTTPS
   estable en `*.ngrok-free.dev` con warning anti-phishing inicial inocuo.
   Patrón repetible para futuros smoke iPhone real.

4. **Auto-status ruta `planificada → en_progreso` al primer cierre** validado
   en producción real con técnico real. Lógica `RutaDiaItemCierreService`
   funcionando.

5. **Foto persistente vía FileUpload Filament/Livewire 3**: el path generado
   `piv-images/ruta-dia-item/{item_id}/{ulid}.jpg` se sirve correctamente vía
   `storage:link`. Borrado físico requiere `rm` manual en cleanup (no hay
   observer DELETE).
