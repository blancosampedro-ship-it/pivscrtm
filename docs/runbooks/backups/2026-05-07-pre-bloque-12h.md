## Lecciones registradas

1. **Smoke real prod sigue cazando lo que tests Pest no** — patrón ya
   consolidado tras 12d/12f/12g, ahora extendido al 12h. Bug del
   trigger A (no_resuelto excluido del derivable) NO estaba cubierto
   por los 28 tests del 12h porque las factories crean items con
   status arbitrario, no replican el flow PWA cierre real. Lección 5
   del checklist (datos prod-shaped) confirmada otra vez.

2. **Mid-smoke fix-PR pattern funciona** — bug detectado a las 20:55
   se mergeó como PR #51 en menos de 30 min sin abortar el smoke.
   Mañana retomamos exactamente donde dejamos (smoke state preservado
   overnight). Patrón consolidado: detectar → prompt fix tight →
   commit → push → PR → merge → continuar.

3. **Protective overnight revert lv_revision_pendiente.id=1** evitó
   contaminación cron 12b.4. Single UPDATE protectivo permite pausar
   smoke largo sin cleanup completo. Replicable para futuros smokes
   multi-día.

4. **CASCADE chain `lv_ruta_dia → lv_ruta_dia_item`** funcionando con
   `lv_derivacion` también: aunque las derivaciones referencian items,
   el CASCADE FK está configurado para que un DELETE de la ruta cascade
   limpiamente a items, y derivaciones (huérfanas tras CASCADE de
   items, también CASCADE en su FK item_id). Cleanup de 5 deriv + 1
   ruta + 29 items en 3 sentencias atómicas.

5. **`Select->searchable()` con `getSearchResultsUsing` no muestra
   opciones por defecto** (hay que escribir 1+ chars). UX detalle a
   considerar para futuros bloques con muchos items.

6. **Notification "Derivación actualizada" en lugar de "creada"** —
   defecto Filament 3 que usa siempre el mismo string genérico de
   action. Cosmetic only, no bloquea funcionalidad. Mini-PR posterior
   opcional con `successNotificationTitle()` explícito.
